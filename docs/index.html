规则集

13 套 · 点按钮直接复制对应格式的链接

每套规则一个文件夹，里面是规则文件加一份说明页。Egern 是 .yaml，Quantumult X 和 Loon 是 .list，内容按域名值去重、三边同步。

注：Loon 版条数略有不同——Spotify 31 条、TikTok 38 条、Telegram 45 条，其余与上表一致。China 只在 Egern 里用，QX 和 Loon 的配置里不加，是故意的。

图标库

13 套 · 放在顶层 icon/ 文件夹

图标都是搬来的原图（主要来自 ddgksf2013/Icon 和 Koolson/Qure），文件夹里留了 13 张预览图（preview-01 到 preview-13）看效果。下面每张预览都能跟着滑杆缩放，先调到你顺眼的大小再挑。

怎么加进软件：每套图标下面有两颗按钮——蓝色按钮直接加进 QX，点了就跳进 QX 问你要不要添加；绿色按钮是 Egern 的，Egern 没有一键导入图标的功能，点了打开的是图标集 JSON 链接，复制后去 Egern 的图标库里粘贴添加。 全部 13 张原图预览在 仓库 icon/ 文件夹 里。

怎么用

按你用的软件看
  1. DNS 转发：设置 → DNS 转发 → 添加规则集，粘贴 China 的链接，策略选国内。DNS 转发是查域名用的：国内域名问国内 DNS 拿到国内 IP，国外域名问国外 DNS。只加 China 就够了，其他规则不用加 DNS 转发。
  2. 分流：设置 → 分流 → 添加规则集，粘贴对应链接，策略按上面卡片选。分流决定流量走哪条路：China、Apple、SausageMan 走直连；Google、Microsoft、AI_Part 走代理节点组；GoogleAds 走拒绝拦截。GEOIP CN 规则排在倒数第二，最后一条才是兜底。
  3. GeoIP 库：设置 → GeoIP 数据库 → 粘贴下面 GeoIpCN.mmdb 的链接。
  4. 模块：工具 → 模块 → 点 +，粘贴模块链接。
https://raw.githubusercontent.com/YuTalk/tool/main/GeoIpCN.mmdb
  1. 分流规则：配置文件 [filter_remote] 里逐条粘贴 QX 版（.list）链接，策略按卡片选：China 直连、Google 谷歌服务、GoogleAds reject、Apple 直连、Microsoft 微软服务、SausageMan 直连、AI_Part 人工智能、GeoIP_CN 直连。
  2. 模块：QX 里直接加远程模块链接（[rewrite_remote] / 资源库），和 Egern 用同一批链接。
  3. 图标：点图标库里的蓝色按钮，直接跳进 QX 添加，不用自己复制。

QX 的配置里不加 China，只在 Egern 里用。

  1. 远程规则：配置 → 规则 → 远程规则，粘贴 Loon 版（.list）链接，策略按卡片选，GEOIP CN 同样放倒数第二。
  2. 插件：仓库里的模块是 Egern 格式，Loon 不能直接装；同一个模块有 Loon 插件版的，用原作者的 Loon 版链接添加。

Loon 的配置里不加 China，只在 Egern 里用。
